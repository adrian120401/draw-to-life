# Draw to Life

Aplicación local que transforma una foto de un dibujo en una mascota 2D
animada. La experiencia está pensada para mostrar y compartir con niños:
una acción para subir, una espera comprensible y una mascota con la que jugar.

La generación usa los modelos locales y conserva el catálogo, la CLI y los
paquetes portátiles. No se usan servicios externos para analizar o generar.
El HTML exportado permite jugar sin servidor ni conexión.

Esta etapa incluye foto desde cámara o galería, HEIC/HEIF y acceso optativo desde
la misma Wi-Fi. La escena permite arrastrar comida hasta la boca, acariciar,
hacer cosquillas y lanzar una pelota que la mascota persigue y empuja. Combina
reacciones rápidas, parpadeo, expresiones y sonidos cortos que se pueden silenciar.
Un minijuego de cinco burbujas suma aciertos inmediatos, una última burbuja
dorada y una celebración breve. Permite salir o repetir, sin cuenta regresiva,
derrotas ni progreso persistente. Funciona con toque, ratón y teclado.
Las reacciones se adaptan a las piezas presentes; no se agregan brazos.
No incluye voz, necesidades, monedas ni progreso guardado.

La interfaz usa español rioplatense y textos mínimos. El usuario pidió un
fondo infantil violeta con formas y un flujo de tres pantallas sin encabezados.
